# Changelog

All notable changes to the PyHP starter are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

Every change is added under **[@dev]** as soon as it's made; when a version is released, those entries move under its number.

## [@dev]

## [0.1.0] - 2026-11-08

### Added
- The starter: `SalesReport` (pandas) and `RevenueChart` (matplotlib) services, a CLI report, a web page, Pest tests, `extra.pyhp` with a universal `pyhp.lock`, `pyhp setup` after `create-project`, and Composer scripts for setup, info, tests and a local server.
